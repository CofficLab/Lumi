
# AskUserPlugin 实现计划（dev 分支）

## 背景

4.19.0 的 AskUser 功能在 dev 分支上内核基础设施大部分已就位：
- ✅ `LumiAskUserMarkers`（pending/error 前缀 + isPendingResponse）
- ✅ `ToolCallResult.awaitingUserResponse`、`AgentTurnOutcome.awaitingUserResponse`、`LumiTurnEndReason.awaitingUserResponse`
- ✅ `AgentTurnRunner` 检测 pending 标记并暂停循环、返回 `.awaitingUserResponse`
- ✅ `.lumiAskUserDidAnswer` 通知名 + userInfo key 已声明
- ✅ `ToolCallRowRenderer` + `ToolCallRowRendererRegistry` 自定义渲染扩展点

需要补的是：工具实现、UI 视图、Bridge、Resume 观察者，以及 LumiFactory 注册。

## 架构决策

**Resume 观察者放在 AskUserPlugin 自身**，通过 `onBoot` 注册通知观察者，用 `kernel.messageManager` 查找/覆盖 pending toolCall result，然后调用 `kernel.agentTurnRunner?.runTurn(in:)` 重启 turn。

理由：
- dev 上没有 ChatService，职责已分解到各插件
- AskUser 逻辑自包含最干净，无需独立小插件
- 无需修改 AgentTurnRunner

## 各组件设计

### 1. AskUserPlugin.swift
- `@MainActor public final class AskUserPlugin: LumiPlugin`
- `id = "plugin-ask-user"`, `policy = .alwaysOn`, `stage = .beta`
- `agentTools(kernel:)` → 返回 `[AskUserTool()]`
- `messageRenderers(kernel:)` → 注册 `AskUserRowRenderer()` 到 `ToolCallRowRendererRegistry.shared`
- `onBoot(kernel:)` → 保存 kernel 引用，启动 `AskUserResumeObserver.shared.start(kernel:)`

### 2. AskUserTool.swift
- 实现 `LumiAgentTool` 协议
- `info.id = "ask_user"`，tags 含 `.userInteraction`
- 参数：`question`（string，必填）、`options`（array of string，可选）、`allow_free_input`（bool，可选）
- `execute` 流程：
  1. 校验 question 非空
  2. 多选关键词检测（无 options 时提示）
  3. 读取 kernel 的 verbosity（从 `kernel.toolExecutionContextState` 或默认 "standard"）
  4. 构造 `AskUserPendingResponse` → JSON 编码 → 返回 `\(pendingPrefix)\n\(json)`

### 3. AskUserModels.swift
- `AskUserPendingResponse: Codable` — toolCallId, question, options, allowFreeInput, conversationId, verbosity
- `AskUserErrorResponse: Codable` — error

### 4. AskUserRowRenderer.swift
- 实现 `ToolCallRowRenderer`（来自 AgentToolKit）
- `id = "ask-user-row"`, `priority = 100`
- `canRender(toolCall:)` — toolCall.name == "ask_user" && awaitingUserResponse
- `render(toolCall:message:)` — 解析 JSON，按 verbosity 分发到 Brief/Standard/Detailed 视图
- 注意：dev 上 `ToolCall` 是 AgentToolKit 的类型，渲染器拿到的是 AgentToolKit ToolCall，需要 `LumiToolCallAgentBridge` 的 `agentToolCall` 扩展来转换

### 5. AskUserBriefView / StandardView / DetailedView
- 与 4.19.0 基本一致，但 `submitAnswer` 改为调用 `AskUserBridge.shared.resume(...)`
- 注意 dev 上的 ToolCall 来自 AgentToolKit，不是 LumiToolCall

### 6. AskUserBridge.swift
- `@MainActor public final class AskUserBridge`，单例
- `resume(conversationId:toolCallId:answer:)` → post `.lumiAskUserDidAnswer` 通知

### 7. AskUserResumeObserver.swift（关键新代码）
- `@MainActor public final class AskUserResumeObserver`
- `start(kernel:)`：
  - 保存 kernel 引用
  - 注册 `NotificationCenter.default.addObserver(forName: .lumiAskUserDidAnswer, ...)`
  - 保存 observer token 以便清理
- 收到通知后：
  1. 从 userInfo 解析 conversationID、toolCallID、answer
  2. 通过 `kernel.messageManager.messages(for:)` 查找包含该 toolCallID 的 assistant 消息
  3. 调用 `kernel.messageManager.updateToolCallResult(_:toolCallID:assistantMessageID:in:)` 用真实 answer 覆盖 pending result
  4. 启动 Task 调用 `kernel.agentTurnRunner?.runTurn(in:)` 重启 turn

### 8. Package.swift
- 依赖：`LumiKernel`、`AgentToolKit`、`SuperLogKit`、`LocalizationKit`（如需）
- 参考 `ProjectOverviewPlugin/Package.swift` 模式

### 9. LumiFactory 注册
- 在 `Packages/LumiFactory/Package.swift` 的 dependencies 中加 `.package(path: "../../Plugins/AskUserPlugin")`
- 在 `Packages/LumiFactory/Package.swift` 的 target dependencies 中加 `"AskUserPlugin"`
- 在 `Packages/LumiFactory/Sources/LumiFactory/Services/PluginService.swift` 的插件列表加 `AskUserPlugin()`

## 与 4.19.0 的关键差异

| 项 | 4.19.0 | dev |
|----|--------|-----|
| 插件协议 | `LumiPlugin` + `LumiPluginContext` | `LumiPlugin` + `LumiKernel` 直接引用 |
| 工具协议 | `SuperAgentTool` + `.asLumiAgentTool()` 适配 | 直接 `LumiAgentTool` |
| 参数类型 | `ToolArgument`（Any wrapper） | `LumiJSONValue`（类型安全 enum） |
| 恢复机制 | ChatService 监听通知 + `resumeAfterAskUser` + `continueAgentTurn` | AskUserResumeObserver 监听通知 + 直接覆盖 result + `agentTurnRunner.runTurn` |
| ToolCall 类型 | `LumiToolCall`（Kernel 内） | 渲染器用 AgentToolKit 的 `ToolCall`，消息里是 `LumiToolCall`，通过 `LumiToolCallAgentBridge` 转换 |
| 插件注册 | Xcode project 直接引用 | LumiFactory 运行时注册 |
