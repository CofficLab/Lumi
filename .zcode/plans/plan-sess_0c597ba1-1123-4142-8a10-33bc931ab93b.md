# 改造方案：EditorBreadcrumbNavPlugin → ProjectFileBreadcrumbPlugin

## 背景与目标

`EditorBreadcrumbNavPlugin` 目前是**死代码**：`policy = .disabled`、`panelHeaderItems` 返回 `[]`、视图层依赖已删除的 `LumiCoreAccessing` 协议（commit `d698e7c87` 删了 `LumiCorePlugin` 包，全仓 10 处引用都是迁移滞后）和 `EditorService`。

目标：重命名为 `ProjectFileBreadcrumbPlugin`，**只对 `LumiKernel` 负责**，监听当前文件路径展示面包屑，点击跳转用 `kernel.editorProvider?.openFile(at:)`。完全去除 `EditorService` 和 `LumiCoreAccessing` 依赖。

可行性已确认：
- `kernel.project?.currentFileURL`（`ProjectProviding`，`@Published`）— 文件路径来源
- `kernel.project?.currentProject?.path` — 项目根来源
- `kernel.project?.objectWillChange` 可订阅（`ProjectProviding: ObservableObject` 带 `ObjectWillChangePublisher == ObservableObjectPublisher` 约束）
- `kernel.editorProvider?.openFile(at: String) async throws` — 跳转入口（用户选定）
- 全仓无外部引用旧名，重命名是自包含的

## 步骤

### 1. 重命名目录（用 git mv 保留历史）
```
git mv Plugins/EditorBreadcrumbNavPlugin Plugins/ProjectFileBreadcrumbPlugin
```
（`Resources/`、`Sources/`、`Tests/`、`.gitignore` 随之移动）

### 2. Package.swift
- 包名/产品名/target名：`EditorBreadcrumbNavPlugin` → `ProjectFileBreadcrumbPlugin`，测试 target `EditorBreadcrumbNavPluginTests` → `ProjectFileBreadcrumbPluginTests`
- **移除** `.package(path: "../../Packages/EditorService")` 和 `.product(name: "EditorService", package: "EditorService")`
- 保留 `LumiKernel`、`LocalizationKit`、`LumiUI`

### 3. 插件入口 — `Sources/EditorBreadcrumbNavPlugin.swift` → `Sources/ProjectFileBreadcrumbPlugin.swift`
- 类名 `EditorBreadcrumbNavPlugin` → `ProjectFileBreadcrumbPlugin`
- `id`：`com.coffic.lumi.plugin.editor-breadcrumb-header` → `com.coffic.lumi.plugin.project-file-breadcrumb`
- `name` key：`"Editor Breadcrumb Header"` → `"Project File Breadcrumb"`
- `policy`：`.disabled` → `.alwaysOn`（与 `ProjectFilesPlugin` 一致）
- **`import EditorService` 删除**
- **接线 `panelHeaderItems`**（核心改动，原来是 `[]`）：
  ```swift
  public func panelHeaderItems(kernel: LumiKernel) -> [PanelHeaderItem] {
      [PanelHeaderItem(id: id) { ProjectFileBreadcrumbHeaderView(kernel: kernel) }]
  }
  ```
- 删除两个编辑器专属 stub（`registerEditorExtensions`、`configureEditorRuntime`）——本插件不再是编辑器子插件，对编辑器细节无知；其余 stub 保留以匹配 `ProjectFilesPlugin` 约定。

### 4. 新增订阅适配器 — `Sources/Services/ProjectFileBreadcrumbObserver.swift`（新文件）
照搬 `ProjectFilesState.swift:33-54` 的验证范式（转发 `objectWillChange`，视图里读 live 值，天然避开 Combine 旧值陷阱）：
```swift
import Combine
import LumiKernel

@MainActor
final class ProjectFileBreadcrumbObserver: ObservableObject {
    private var cancellable: AnyCancellable?
    private let project: (any ProjectProviding)?

    init(project: (any ProjectProviding)?) {
        self.project = project
        bind()
    }

    private func bind() {
        cancellable = project?.objectWillChange.sink { [weak self] _ in
            self?.objectWillChange.send()
        }
    }
}
```

### 5. 视图层重命名 + 改写

**`NavHeaderView` → `ProjectFileBreadcrumbHeaderView`**（`Sources/Views/NavHeaderView.swift`）
- 去掉 `@ObservedObject service: EditorService` 和 `lumiCore: LumiCoreAccessing`
- 改为 `let kernel: LumiKernel` + `@StateObject observer: ProjectFileBreadcrumbObserver`
- `init(service:lumiCore:)` → `init(kernel:)`（参考 `ProjectFilesHeaderView.swift:11-16` 的 `@StateObject` 写法）
- `service.files.currentFileURL` → `kernel.project?.currentFileURL?.standardizedFileURL`（live 读）
- `lumiCore.projectComponent.currentProject` → `kernel.project?.currentProject`
- `lumiCore.projectComponent.currentProject?.path` → `kernel.project?.currentProject?.path`
- `breadcrumbPath` 里 `NavPathView(fileURL:service:lumiCore:)` → `ProjectFileBreadcrumbPathView(fileURL:kernel:)`
- `isFile(_:inProjectPath:)` 静态方法逻辑不变（被单测引用，需同步改名）
- 删 `import EditorService`

**`NavPathView` → `ProjectFileBreadcrumbPathView`**（`Sources/Views/NavPathView.swift`）
- 同样 `service`/`lumiCore` → `kernel: LumiKernel`
- `currentProjectPath` 改读 `kernel.project?.currentProject?.path`
- **点击跳转闭包重写**（`NavPathView.swift:96-106`）：
  ```swift
  onSelectFile: { url in
      let rawProjectPath = currentProjectPath.trimmingCharacters(in: .whitespacesAndNewlines)
      guard !rawProjectPath.isEmpty else { return }
      guard ProjectFileBreadcrumbHeaderView.isFile(url, inProjectPath: rawProjectPath) else { return }
      Task { @MainActor in
          try? await kernel.editorProvider?.openFile(at: url.path)
      }
  }
  ```
  说明：原 `service.refreshProjectContext(for:)` 调用**移除**（属项目索引关注点，非面包屑职责；用户只指定 openFile 做跳转）。
- 删 `import EditorService`

**其余文件保持不变**（降低改动面）：
- `Sources/Models/BreadcrumbItem.swift` — 模型，无依赖，不改
- `Sources/Views/NavComponent.swift`、`MenuContent.swift`、`MenuRow.swift` — 已只依赖 `LumiUI`，不改名不改内容
- `Sources/BreadcrumbNavIconStyle.swift` — 图标策略，不改
- `Sources/Services/LumiPluginLocalization.swift` — 仅文档注释里 "EditorBreadcrumbNavPlugin bundle" → "ProjectFileBreadcrumbPlugin bundle"
