04

明确不显示的东西

空态是提问入口，不是仪表盘。以下内容即使技术上取得到，也一律不进首屏。

文件树预览

重、且与左侧文件树重复，首屏还要做目录遍历 IO。

替代：只给一行「目录 · N 个文件」，放进展开态

README 摘要

一大段文字会直接杀死首屏焦点，用户的视线会被拉进长文。

替代：README.md 做成一个标签，点开再看

分支名

标题栏的 GitBranchToolbarButton 已经常驻显示，重复即噪音。

替代：只补 dirty 计数，分支名交给工具栏

记忆条数 / 规则条数

ProviderAgentRules 只有 contributor 维度，没有项目维度；记忆插件同样没有对应 Provider。

替代：「有 AGENTS.md」——信息量更足，且只是本地 stat
