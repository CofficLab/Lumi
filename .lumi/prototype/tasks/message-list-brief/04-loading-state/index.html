遮罩而不是骨架屏 MessageLoadingView 是一张半透明遮罩 + 简短文案。消息条数未知时，骨架屏反而会闪烁。
2
就绪前不接受点击 allowsHitTesting(isInitialPositionReady) —— 定位完成前列表不可交互，避免点到一半跳动的行。
3
「加载更早」独立于初始加载 翻页是按需的：只有存在更早消息时才出现入口，加载中就地变成 spinner，不遮挡当前视图。
