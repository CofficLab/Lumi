# White Noise Plugin

实时生成白噪音、粉噪音、棕噪音，用于专注或助眠。

## 功能

- **实时算法生成**：基于 `AVAudioEngine` + `AVAudioSourceNode` 逐帧生成，无音频文件、真正无缝循环。
- **三轨混合**：白噪声 / 粉噪声 / 棕噪声可独立开关、各自调节音量，混合后输出。
- **主音量**：统一控制整体输出强度。
- **睡眠定时器**：15 / 30 / 60 分钟后自动停止，带倒计时。
- **与其它音频混音**：以 `.playback` + `.mixWithOthers` 运行，不打断你正在听的音乐。

## 三种噪声的区别

| 类型 | 频谱 | 听感 |
|------|------|------|
| White Noise | 全频段等能量 | 尖锐的「沙沙」声 |
| Pink Noise | 每倍频能量恒定 | 柔和，常用于专注 / 掩蔽 |
| Brown Noise | 能量集中在低频 | 低沉，类似海浪 / 远雷 |

## 技术实现

- **粉噪声**：Paul Kellet 多阶滤波算法。
- **棕噪声**：对白噪声积分。
- **线程安全**：实时音频线程与 UI 主线程通过 `OSAllocatedUnfairLock<AudioState>` 单锁同步控制量（开关、音量）与滤波器系数；非公平自旋锁无优先级反转，适合实时音频。
- **幅值归一化**：粉噪声 ×0.18、棕噪声 ×3.5 归一化，并做软限幅避免混合叠加爆音。

## 如何启用

插件默认关闭（`optIn`）。在 **插件管理** 中找到 "White Noise" 并启用，随后会在侧边栏 ActivityBar 出现对应容器。
