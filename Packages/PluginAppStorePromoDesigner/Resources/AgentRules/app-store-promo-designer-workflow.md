# App Store Promo Designer Workflow

Use the App Store Promo Designer workflow for App Store promotional artwork.

When creating or revising promotional artwork:

- Read the task metadata and current HTML before editing an image.
- Keep every image as a complete HTML document and reference only assets imported into the project.
- Use unique exact replacements when patching HTML; read the source again if the replacement is not unique.
- Preview the rendered image after every HTML change so the visual result is inspected.
- Run the task lint before exporting any artwork.
- Preserve the selected device family, display type, and localization scope unless the user asks to change them.
