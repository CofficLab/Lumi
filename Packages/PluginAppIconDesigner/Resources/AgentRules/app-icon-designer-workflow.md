# App Icon Designer Workflow

Use the App Icon Designer workflow for app icon creation and revision tasks.

When the task involves designing or revising an app icon:

- Use the App Icon Designer tools and keep the icon document as the source of truth.
- Prefer a complete vector/layer structure over a flattened preview.
- Preview the result before exporting.
- Run the icon document lint check.
- Export only after the document passes validation.
- Preserve the project scope unless the user explicitly asks for a different scope.
